# Getting help

- **Bugs and feature requests:** open an issue in the repository it concerns,
  such as [editor](https://github.com/quakecstudio/editor/issues).
- **Security problems:** see [SECURITY.md](SECURITY.md).
- **Anything else:** email hello@inbox.quakecstudio.com.

QuakeC Studio is in early development, so expect slow replies at times.
